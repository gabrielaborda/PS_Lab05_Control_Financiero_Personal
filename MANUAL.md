# Manual de Usuario

Este manual explica cómo usar la aplicación para llevar un control simple y claro de tus finanzas personales.

## 1. Registro e inicio de sesión

- Accede a la pantalla de registro.
- Completa tu nombre, correo electrónico y contraseña.
- Usa el mismo correo y contraseña para iniciar sesión.
- Si ya estás registrado, ve a la pantalla de inicio de sesión.

## 2. Cómo agregar ingresos y gastos

- En el menú, abre la sección de transacciones.
- Elige "Crear transacción".
- Completa la descripción de la operación.
- Ingresa el monto.
- Selecciona si es `ingreso` o `gasto`.
- Elige una categoría existente.
- Selecciona la fecha de la transacción.
- Guarda la transacción.

### Consejos rápidos
- Usa descripciones claras como "salario" o "compra supermercado".
- Revisa que el monto sea positivo.
- Selecciona la categoría que mejor describa la operación.

## 3. Crear y administrar categorías

- Ve a la sección de categorías.
- Crea nuevas categorías cuando necesites ordenar mejor tus ingresos y gastos.
- Al crear una categoría, define si será para `ingreso` o `gasto`.
- Puedes editar el nombre o eliminar categorías que ya no uses.
- Usa iconos o nombres cortos para reconocerlas rápido.

### Buenas prácticas
- Crea categorías de gasto como "Alimentos", "Transporte" o "Entretenimiento".
- Crea categorías de ingreso como "Salario" o "Ventas".
- Mantén las categorías limpias para un mejor análisis.

## 4. Configurar presupuestos

- En la sección de categorías, elige una categoría de gasto.
- Establece un presupuesto mensual para esa categoría.
- Define el monto que deseas gastar ese mes.
- Guarda el presupuesto.

### Qué hace el presupuesto
- La aplicación compara el gasto real con el presupuesto definido.
- Cuando el gasto se acerca o supera el presupuesto, el sistema muestra una alerta.
- Esto te ayuda a controlar mejor tus gastos por categoría.

## 5. Interpretar el dashboard

El dashboard es tu vista general de finanzas.

### Qué verás en el dashboard
- Total de ingresos.
- Total de gastos.
- Saldo disponible.
- Transacciones recientes.
- Alertas de presupuesto.

### Cómo usarlo
- Revisa el saldo para saber si estás gastando menos de lo que ingresas.
- Observa las alertas para categorías con gasto alto.
- Usa los reportes para ver tendencias en el tiempo.

## 6. Cómo filtrar y revisar transacciones

- Abre la lista de transacciones.
- Usa filtros por tipo, categoría o fechas.
- Busca operaciones específicas por período.
- Cambia de página para ver más transacciones.

## 7. Recomendaciones generales

- Registra tus operaciones tan pronto como ocurran.
- Usa categorías claras y consistentes.
- Revisa el dashboard regularmente.
- Ajusta presupuestos según tus necesidades.
- Usa las alertas para evitar gastar de más.
